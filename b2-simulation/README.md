# محاكاة افتراضية — B-2 Spirit / جبل الفأس (نطنز)

فيديو وثائقي استقصائي مدته 120 ثانية بنسبة 16:9 ودقة 1920×1080. يُرسم بالكامل في المتصفح باستخدام WebGL (Three.js)، ويُصدَّر كملف MP4 مع الصوت.

> **محاكاة افتراضية لأغراض توضيحية - ليست لقطات حقيقية أو تنبؤات علمية دقيقة.**
> يظهر هذا التنبيه أسفل الشاشة طوال العرض. طبقة الغبار المشع رسم توضيحي نوعي (أعلى ← أدنى) ولا تحتوي أي قيم كمية: لا قدرة تفجيرية ولا أنصاف أقطار ولا جرعات.

## التشغيل

تحميل الصور كـ textures لا يعمل عبر `file://`، لذلك شغّل خادماً محلياً من جذر المستودع:

```bash
npm install
npm run b2:serve        # ثم افتح http://localhost:8080/b2-simulation/
```

المفاتيح: `مسافة` للتشغيل والإيقاف، و`1`–`4` للانتقال بين المشاهد، و`←`/`→` للترجيع والتقديم، و`F` لملء الشاشة. زر `WAV` يصدّر شريط الصوت وحده.

## تصدير الفيديو

يتطلب Google Chrome و ffmpeg. عند عدم وجود كرت شاشة يعمل التصدير عبر SwiftShader (رسم برمجي)، ويستغرق الإطار الواحد نحو 1.5–4 ثوانٍ، أي عدة ساعات للفيديو كاملاً (يمكن تقسيمه بـ `--from`/`--to` وتشغيل الأجزاء بالتوازي).

```bash
npm run b2:export                                           # b2-simulation/out/b2-simulation.mp4
node b2-simulation/tools/export.mjs --from 35 --to 60      # جزء من الفيديو
node b2-simulation/tools/export.mjs --stills 20,40,70       # لقطات PNG للمراجعة
```

## العمل الهجين مع أدوات الفيديو بالذكاء الاصطناعي

الملف [`AI_PROMPTS.md`](AI_PROMPTS.md) يحتوي برومبتات جاهزة لـ Veo وSora وRunway وKling للقطات الفوتوغرافية (B-2 والانفجار)، مع قائمة لقطات بتوقيت الريندر نفسه، ودليل للدمج ومطابقة الألوان، وجدول للمؤثرات الصوتية. الريندر يعطي خريطة كاملة صحيحة جغرافياً، ويمكن استبدال لقطات المشهدين ٢ و٣ بلقطات الذكاء الاصطناعي في المونتاج مع إبقاء التسميات وتنبيه المحاكاة من الريندر.

## تغيير الهدف

الموقع معرّف في `js/geo.js` (`TARGET`). صور التفاصيل العالية تغطي المنطقة المحيطة بنطنز فقط، لذلك عند تغيير الموقع عدّل الحدود في `tools/fetch_tiles.py` ثم أعد التنزيل:

```bash
uv run --with pillow --with numpy b2-simulation/tools/fetch_tiles.py
```

## المصادر والتراخيص

- NASA Blue Marble Next Generation مع تضاريس قاع المحيط، و VIIRS Black Marble 2016، و HLS (Harmonized Landsat Sentinel-2) لنطنز ودييغو غارسيا، عبر NASA GIBS (ملكية عامة).
- Sentinel-2 cloudless 2016 من EOX، ترخيص CC BY 4.0 (يتضمن بيانات Copernicus Sentinel معدّلة، 2016).
- بيانات الارتفاع: Terrain Tiles (Mapzen / AWS Open Data). الحدود: Natural Earth عبر world-atlas.
- صورة الطائرة العلوية `assets/b2-top.png` قدّمها المستخدم، ويُستخرج منها شكل الطائرة ثلاثي الأبعاد (حدود الأجنحة) وتُستخدم كخامة للسطح العلوي.
- Three.js (ترخيص MIT، `vendor/THREE-LICENSE`). الخطوط: Cairo و Tajawal (SIL OFL).
- موقع «جبل الفأس» (كوه كلنگ گزلا) تقريبي ومأخوذ من تقارير مفتوحة. التضاريس مضخّمة رأسياً ×1.6 لإبراز الطبيعة الجبلية.
