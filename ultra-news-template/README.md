# قالب ألترا صوت — خبري عنوان (After Effects)

سكربت يبني مشروع After Effects كاملاً بمقاس 1080×1920 يطابق قالب الفيديو المرجعي.

## التشغيل
1. افتح After Effects (يُفضّل 2024 أو أحدث لدعم اتجاه النص العربي RTL كاملاً).
2. `File > Scripts > Run Script File...` واختر `UltraSawt_NewsTemplate.jsx`.
3. سيطلب منك:
   - **فيديو المادة** (اختياري) — تُضبط مدة الكومب وعدد الإطارات تلقائياً عليه.
   - **ملف الشعار** الأبيض بخلفية شفافة (PNG/AI/PSD) — اختياري؛ عند الإلغاء يُوضع شعار نصي مؤقت.
4. في النهاية يمكنك حفظ المشروع مباشرة كملف `.aep`.

> إذا لم يظهر الخط صحيحاً: غيّر `fontAr` أعلى السكربت إلى اسم PostScript لخط مثبت عندك (مثل `Almarai-ExtraBold` أو `Tajawal-Bold`)، أو غيّره من لوحة Character بعد البناء.

## محتوى المشروع
| الطبقة / الكومب | الوظيفة |
|---|---|
| `HEADLINE_BIG` | العنوان الكبير بتأثير الكتابة + مؤشر، ثم يُمسح عند 8 ثوانٍ |
| `HEADLINE_LOWER` | العنوان المختصر بسطرين أسفل الشاشة حتى النهاية |
| `ICON_BIG` / `ICON_LOWER` | أيقونة ألترا الحمراء تنبثق من الأبيض إلى الأحمر |
| `BIG_DECO_LINE` | الخط العمودي المزخرف بجانب العنوان |
| `LOCATION_CTRL` + `LOC_*` | وسم الموقع (المعين الأحمر + الدبوس + النص + الخط المنقّط الذي يتبع طول النص تلقائياً) |
| `CREDIT_CTRL` + `CREDIT_*` | أيقونة إنستغرام واسم المصوّر عمودياً |
| `LOGO_ULTRA_SAWT` | الشعار: يُرسم كإطار ثم يمتلئ بوميض، ويتكرر كل 8 ثوانٍ |
| `LOGO_SOURCE` | **ضع شعارك الحقيقي هنا** ليتحدّث في كل مكان |
| `END_FADE` | إظلام الفيديو في آخر 0.7 ثانية مع بقاء العنوان والموقع |

## التعديل السريع
- **النصوص**: عدّل Source Text مباشرة في الطبقة (العنوان، الموقع، الاسم). استخدم Enter لكسر السطر.
- **توقيت الكتابة**: مفاتيح `Effects > Type Progress` على كل طبقة نص (0 → 100).
- **إظهار/إخفاء المؤشر**: خانة `Cursor` في نفس الطبقة.
- **تحريك عنصر كامل**: حرّك الـ Null المسمّى `*_CTRL`.
- **التوقيتات الافتراضية والألوان**: كائن `CFG` أعلى السكربت (اللون الأحمر `C8102E`).
