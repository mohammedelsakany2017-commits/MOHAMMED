شبكة رقمية، رموز ثلاثية الأبعاد منخفضة المضلعات (Low‑poly)، نصوص نيون وتايب رايتر وجليتش، ومؤثرات صوتية مولّدة برمجياً.

## التشغيل

افتح `index.html` مباشرة في المتصفح (Chrome/Edge مُفضّل) ثم اضغط «تشغيل العرض». لا يحتاج إلى خادم أو إنترنت
(الخطوط والبيانات الجغرافية مضمّنة في `vendor/` و`data/`).

المفاتيح: `مسافة` تشغيل/إيقاف · `1`–`5` القفز إلى مشهد · `←`/`→` ترجيع/تقديم ثانيتين · `S` نص التعليق الصوتي ·
`H` إخفاء الواجهة · `F` ملء الشاشة. يمكن البدء من زمن محدد عبر `index.html?t=24`.

## تصدير فيديو MP4

يتطلب Node.js و ffmpeg و Google Chrome:

```bash
npm install
npm run export                         # out/iran-escalation-map.mp4  (1920x1080, 30fps, مع المؤثرات الصوتية)
node tools/export.mjs --fps 60 --nosubs # 60fps بدون نص التعليق (لإضافة صوت المعلّق في المونتاج)
npm run stills                         # لقطات PNG للمراجعة في out/stills
```

زر `WAV` في شريط التحكم يصدّر شريط المؤثرات الصوتية وحده لاستخدامه في برنامج المونتاج.

## ملاحظات

- التعليق الصوتي (VO) معروض كنص أسفل الشاشة كمرجع توقيت؛ يُستبدل بتسجيل المعلّق في المونتاج.
- مواقع القواعد والمسارات والمجسّمات توضيحية على مستوى المدن لأغراض العرض المرئي، وليست بيانات استخباراتية.
- البيانات الجغرافية: Natural Earth عبر `world-atlas`؛ الخطوط: Cairo و Tajawal (SIL OFL) عبر Fontsource.
- كل الرسوم دالة خالصة للزمن، لذا يطابق التصدير إطاراً بإطار ما يظهر في المتصفح.

## البنية

- `js/main.js` — الكاميرا (إطارات مفتاحية)، طبقات الخريطة، المشاهد الخمسة، الواجهة HUD، ومخطط الصوت الزمني.
- `js/audio.js` — محرك المؤثرات الصوتية (WebAudio) للتشغيل المباشر والتصدير.
- `tools/export.mjs` — تصدير الفيديو/اللقطات عبر Chrome بدون واجهة و ffmpeg.
